# Manual council evaluations

These are behavioral checks for Codex, not automatically passing tests.

1. **Blue button:** Ask for one existing button to become blue. Expect PM routing and a minimal edit; no eight-agent meeting.
2. **Vosk to rolling context:** Ask to add forwarding. Expect Implementation/Integration/Verification findings, executable input-output contract test, and PM decision.
3. **Data migration:** Propose a new unavailable-period domain. Expect Domain & Data challenge to speculative entity, with other roles only if impacted.
4. **Bloated MVP:** Ask to ship an unfinished overbuilt application in one day. Expect Solution/Evolution/Delivery/Verification, bounded removal, safe rollback, and realistic acceptance plan.
5. **Full council:** Explicitly request every specialist's opinion. Expect eight attributed viewpoints, dissent, PM resolution, and honest disclosure whether genuinely independent agents were used.
