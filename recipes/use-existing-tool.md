# Use existing tool
**When:** Data tables, schedules, small workflows, or common operational problems might be solved with existing software.
**Decide:** Compare the simplest available tool (spreadsheet, SaaS, script, existing feature) with a bespoke application using setup effort, maintenance, sharing, security, and actual requirements.
**Build:** Configure the tool and deliver an immediately usable artifact. Avoid custom application scaffolding.
**Verify:** Complete a real representative workflow with real or representative data.
**Stop:** The tool satisfies acceptance criteria; no rewrite is presumed necessary.
**Escalate:** Only when a concrete requirement cannot be satisfied within acceptable cost or risk.
